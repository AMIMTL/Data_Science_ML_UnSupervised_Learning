# Data Science in Python: Unsupervised Learning

**Course source:** [Maven Analytics - Data Science in Python: Unsupervised Learning](https://mavenanalytics.io/course/data-science-in-python-unsupervised-learning)

**Instructor:** Maven Analytics  
**Status:** ✅ Completed

## Course Overview
This hands-on, project-based course focuses on mastering unsupervised learning foundations in Python. Through an HR analytics case study (employee retention), you'll learn clustering, anomaly detection, dimensionality reduction, and recommendation engines.

## What You'll Learn

### Data Preparation
- Setting correct row granularity for modeling
- Feature engineering techniques
- Feature selection
- Data scaling (normalization and standardization)

### Clustering Models (scikit-learn)
- **K-Means Clustering** - interpreting cluster centers, inertia plots for optimal clusters
- **Hierarchical Clustering** - dendrograms for cluster identification, cluster maps for interpretation
- **DBSCAN** - detecting clusters and noise points, silhouette score evaluation

### Anomaly Detection
- DBSCAN for outlier detection
- Isolation Forests for identifying anomalous patterns
- Visualizing anomalies with pair plots

### Dimensionality Reduction
- **Principal Component Analysis (PCA)** - feature extraction and data visualization
- **t-SNE** - ideal for data visualization

### Recommendation Engines
- Content-based filtering
- Collaborative filtering
- Cosine Similarity
- Singular Value Decomposition (SVD)

## Course Project: HR Analytics Case Study
You'll play the role of an Associate Data Scientist for the HR Analytics team at a software company trying to increase employee retention. Using Python, you will:
- Segment employees using clustering techniques
- Visualize the clusters
- Recommend next steps to increase retention
